# 设计方案 (Design Documents)

本目录用于存放 GregFood Expansion 的设计方案文档（Markdown 格式），例如：

- 新增食物/物料的机制设计
- 配方与合成路线设计
- 与 GTCEu 及其他模组的联动设计
- 平衡性调整方案

## 内容状态总表

- [content-crops.md](../content-crops.md):作物总表(已加入 / 待加入,按批次)
- [content-foods.md](../content-foods.md):食物总表(食材形态 / 菜肴 / 待加入,按缺失依赖)

## 约定

- 每个方案一个独立 `.md` 文件，文件名使用小写英文与连字符，如 `food-nutrition-system.md`。
- 文档开头建议注明状态（草稿 / 已定稿 / 已实现）与日期。
