# 畜牧与肉蛋奶(Livestock, Meat / Eggs / Dairy)

> **状态:方向已定案 / 数值待收口** — 2026-09-09
>
> 三问自检:① 消费方=菜肴荤料侧+工业(明胶/牛油/骨粉);② 每档给新加工工艺(分割/腌制/熟成/培养蛋白);
> ③ 卡点=饲料品位闭环把作物接进荤菜品质,骨粉血粉接 GT 肥料。

## 1. 源层(~16 个动物源,原版接链为主)

| 层 | 内容 | 数量 |
| --- | --- | --- |
| 原版接链(零成本) | 猪/牛/羊/鸡/兔 五肉种;鳕/鲑/鱿鱼/热带鱼 水产;鸡蛋;牛奶 | 11 |
| 新增实体(真实动物) | **鸭**(咸蛋/皮蛋/烤鸭/鸭血,杠杆最高)、**虾**(白灼/虾仁/虾饺)、**蟹**(蟹黄/大闸蟹)、**鹌鹑**(鹌鹑蛋)、**鹅**(烧鹅/鹅肝) | 5 |

**资产警示**:动物实体(模型+动画+AI+生成规则)是全模组最贵资产类,预算单列、节奏放慢——
**第一批只上鸭**(不上则咸蛋黄/烤鸭/月饼矩阵塌角),虾/蟹/鹌鹑/鹅随菜系包批次(II~III)。

## 2. 肉:按真实肉铺分割转录(~45 形态)

分割学本身是真实谱系——旧版"形态层"在动物侧的合法化:

| 种 | 分割形态(转录自真实肉铺术语) |
| --- | --- |
| 猪 | 五花、里脊、排骨、蹄髈、梅头、猪皮、猪耳、猪肝、大肠、猪蹄 |
| 牛 | 牛腩、牛柳、牛腱、牛排部位、牛尾、牛骨、牛肝、百叶、牛肚 |
| 羊 | 羊排、羊腿、羊蝎子、羊杂 |
| 鸡 | 鸡胸、鸡腿、全翅/翅中/翅根、鸡爪、鸡架、鸡胗、鸡肝 |
| 鱼 | 鱼片、鱼头、鱼骨、鱼腩、鱼杂 |

规则:**生熟分品**(熟鸡可切丝、生鸡不可);分割走家厨工坊切配模式(机器)或厨刀(手工窄路,必须通)。

## 3. 肉加工品(~25)

- **基础处理**:绞肉、肉片、肉丝、肉馅;
- **灌制矩阵(成型家族)**:肠衣(猪大肠刮制)× 肉馅 × 调味 → 香肠族(按菜系包扩 SKU);
- **丸类(成型家族)**:牛肉丸、鱼丸、虾丸;
- **腌腊干制**:培根、火腿(亚硝酸钠腌制,GTCEu 已有 `sodium_nitrite`)、腊肉、肉松、肉脯、午餐肉;
- **B2 供给**:明胶(复用 GTCEu 材料,食品级路线)、高汤底(畜骨/鱼/菌菇)、牛油(食品+蒸馏→润滑剂双两用)。

## 4. 蛋系(~10)

鸡蛋(原版)→ 蛋液/蛋白/蛋黄分离(烘焙基料)、卤蛋、溏心蛋;
**咸蛋黄**(腌制工艺钥匙,MV;咬合点=GTCEu 石膏/石灰系材料)、**皮蛋**(真实工序:石灰+草木灰)、
鸭蛋、鹌鹑蛋。

## 5. 乳系(~20,SKU 跟菜系包走)

- **基础批**:鲜奶、巴氏奶(配方门槛,MV)、黄油、淡奶油、酸奶、炼乳(奶茶)、奶粉、奶油奶酪;
- **西餐烘焙系**:马苏里拉、帕玛森、蓝纹、白霉、马斯卡彭(提拉米苏)、里科塔;
- **菜系扩展**:酥油 Ghee、Paneer(印度包);乳清三条去向全留(里科塔/乳清蛋白→终局/乳糖→生化)。

挤奶定位:畜牧工坊(多方块,MV)——旧单方块挤奶机重置(overview.md 原则 7);原版奶桶为手工备用路线。

## 6. 饲养品位闭环(动物侧意义存续落点)

**饲料品位(豆粕/谷物/胡萝卜配方与品位)→ 肉蛋奶品位 → 菜品增益**。
工业化表达"谷饲/草饲/走地鸡":同一头猪,工业饲料标准品位,高品位饲料喂养超基准产出——
**作物通过饲养永久参与荤菜品质**,是 crops↔livestock 的结构性焊点。

## 7. 工业咬合点

明胶(复用 GTCEu 材料,食品级路线并行 HV 洁净室路线)、牛油→润滑剂(照鱼油先例)、
鱼油(原版提取机)、骨粉/血粉→GTCEu 肥料——荤侧无废料,全部过链(gt-interlocks.md)。

## 8. 数量账

动物系配料合计 **~100~120 条**(分割 45 + 加工 25 + 蛋 10 + 乳 20 + 源产 10~15),
对 3,500~4,000 道菜的荤料杠杆 **~1:35**(换菜不换肉,换工艺与味型)——故动物系
**不追平作物数量级,在 ~110 条饱和**;荤素配料比 ~1:8,符合真实菜谱结构。
