# 终局合成食品(Synthetic Food)

> **状态:已定案(轮廓)** — 2026-09-07
>
> 讨论项 9。五项决议(Q1–Q5)落定,**brainstorm §10-3 UUM 供给悬案就此收口(放弃 UUM 路线)**;营养膏效果表等细节在遗留清单(§9)。

## 1. 定位

支柱 H,EV+。饥饿问题的工业终解。叙事:**GTCEu 用 UUM 回答"物质从哪来",食品线用氨基酸合成回答"饭从哪来"**——与化工终解平行而非借用。

## 2. UUM 决策(决议 Q1,收口 §10-3)

**放弃 UUM 路线,走元素级合成。**

查证坐实(2026-09-07):复制机在 GTCEu 7.5.3 **整体不存在**(全源码仅 `LangHandler.java` 语言条目残留);`UUMatter` 材料存在(`UnknownCompositionMaterials.java:590`)但唯一引用为**注释掉的配方**(`MachineRecipeLoader.java:328`)——三无状态。"接 UUM" = 重建被上游有意移除的系统,+2 多方块级机器与任意物品价值表,且 UUM 产出会溢出到全模组经济(上游砍它的原因)。UUMatter 材料本体保持原样,不注册任何配方。

## 3. 营养膏(决议 Q2)

- 机器:**装配线(复用,EV+)**;配方 = 通用蛋白质 + 通用氨基酸 + 维生素/微量元素 + 水;
- **SKU 2–3 档**(基础/增强/全效):档位递进 = 增益时长与效果种类逐档解锁,**全模组增益天花板**(原则 5 落地);
- 单件高营养密度顶格(与罐头/冻干的压低逻辑相反——终局就该顶格);
- **保留玩家进食动作,不做自动进食**;SoL 每 SKU 计一次,天然有限;
- 上游:通用氨基酸 = 发酵产(味精链同构,谷氨酸发酵先例)+ 蛋白水解(通用蛋白质 + 酶 + 水——酶耐久模型的又一消费点)。

## 4. 培养肉(决议 Q3)

- EV+,生物反应器产出;**独立 SKU,不进 `forge:raw_meat` 等生肉标签**;
- 定位 = 肉品线的工业替代供给(衔接肉品线掺混分流决议),可经切配机/烹饪机走常规熟制;SoL 独立计数;
- 原版动物/狩猎玩法不冲击。

## 5. 螺旋藻(长尾跳队条款落地)

EV+ 光生物反应器培养(原文卖点)→ **并入生物反应器**,光照叙事以高 EUt 表达;产物汇入通用蛋白质(Q5)。

## 6. 机器载体(决议 Q4)

- **新增「生物反应器」多方块(EV+)**:复用化学反应釜配方类型(多方块限定,模仿 GCYM 酿造房先例,不新建配方类型);**只做并行不做环境参数**(同后处理厂收窄先例);
- 承载四类配方:培养肉增殖、螺旋藻光培养、菌种纯培养升级(biochem 产菌延伸)、酶制剂量产(biochem 产酶迁移位)——一个平台四个消费点,支柱 D/H 共用生物终局平台;
- 营养膏挂装配线(见 §3);~~食品合成器~~ 不立项(与装配线重叠,原则 4);
- 资产:1 个多方块,贴图预算 ~6–8 张。

## 7. 材料体系(决议 Q5,收口 dairy §11-3)

- **单一材料**:仅注册 `universal_protein` / `universal_amino_acid`(各带流体/固体形态);
- 乳清(dairy 决议 6 优先级 2)/豌豆(P2)/大豆(大豆链)/螺旋藻均为**获取路线**,GT 多路线一材料风格,与 gelatin 复用决议同构;
- **乳糖独立注册**(甜味剂/医药叙事,dairy 优先级 3),不受本决议影响;
- 维生素/微量元素:营养膏投入项,M0 新增清单扩展(具体清单见 §9-4)。
