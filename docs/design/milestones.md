## 2. M1' 详细范围(首个可玩闭环)

1. **机器**:切配工坊(LV)、烹饪工坊(LV)、隧道烤炉(MV);
2. **作物**:家常覆盖批 ~47 实体 + 11 原版接链(crops.md §4),野生作物生成;
3. **畜牧**:原版五肉种基础分割(~15 形态)、鸡蛋链、乳系基础 SKU(奶源=原版奶桶,挤奶自动化随 M3' 畜牧工坊);
4. **发酵**:酵母自举→发酵面团→面包族;瓶装酒首批(啤酒/葡萄酒/米酒);
5. **菜肴**:手做基线 + A 群首批模板(汤面/炒饭/串/沙拉/包制/饮品)+ B 群旗舰首批(~8 道,全手绘);
6. **增益**:三因子管线 + SoL 桥 + 家常样本集 100 道入 lint;
7. **管线**:三张核心表 schema 落地 + lint 1~9 号规则生效 + 贴图管线(模板调色/分层合成)。

## 3. 验收纪律

- 每批交付含:数据表 PR、贴图批次、runClient 冒烟记录、lint 报告;
- 未过闸不叠下一批(旧版"未验收先叠 M2"教训成文);
