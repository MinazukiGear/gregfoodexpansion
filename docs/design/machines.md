# 机器体系(Machines):多方块优先

> **状态:方向已定案 / 结构细则待收口** — 2026-09-09
>
> 原则 7/11(overview.md):**零新增套皮单方块机器**;**单一用途**——一台多方块只承载一类工艺用途,
> 用途拆分优先于功能合并(家厨工坊已拆分为切配工坊+烹饪工坊),同用途的量产上位不算新用途;
> **例外**:时间转化类工艺(固态发酵/熟成/酒陈酿)同仓模块化为「酿窖」——它们的共同本质是"时间+环境控制";
> **不新增生物**——新动物源产品一律经养殖场多方块虚空生成(镜像姊妹项目采矿厂/钻井语法)。
> 复用 GTCEu 既有机型不受此限(复用不是套皮)。全跨度新增多方块 **20 台**,新增单方块 0 台、新实体 0 个;
> 顶档 UV–UIV 不设机器(元素级合成复用 GT 装配线/反应器),稀疏语法不破。

## 5. 逐台规格(随实装批次追加)

### 5.1 隧道烤炉(MV)——模块化多方块样例

**结构组成**:基础机架(控制器+输入/输出仓+能源仓+输送段)+ 可加装的**炉温段模块**。

| 炉温段模块 | 温度带(真实烘焙对照) | 解锁配方示例 |
| --- | --- | --- |
| 低温段 | 120–160 °C | 果干、烘干、低温慢烤 |
| 中温段 | 170–190 °C | 面包、蛋糕、饼干、酥皮 |
| 高温段 | 210–250 °C | 披萨、硬壳上色、高温快烤 |

**规则**:

1. **配方门槛=结构**:配方绑定炉温档,结构中未安装对应段则该配方不可运行(EMI/Jade 明示缺哪段);
2. **段数=并行**:每个炉温段独立执行一份配方——多段同装既扩配方面也扩并行,多装段有真实回报;
3. **强制预热**:冷机启动需预热时间(段数越多越长),连续生产才是正解(呼应"隧道"叙事);
4. **交付弹性**:基础结构+任意段组合即可运行,模块可跨批次交付(如 M1' 交付低温/中温段,高温段随后续批);
5. 模块为方块物品,扳手拆装回收;同用途的档位扩展不算新用途(原则 7)。

### 后续候选(未立项,防拍脑袋)

净菜处理线(HV)、风味合成塔(UHV,若顶档决定机器化)、藻类光反应器(EV,若从生物反应器拆出)。
立项门槛照三问+三限制+单一用途。

## 2. 手工层(工具与交互方块,非机器)

菜刀/削皮刀/研钵/擀面杖等耐久工具组,以及**陶罐**(篝火炖煮/常温发酵交互方块,
见 food-processing.md §手工炊事载体)——均不属机器,不进本表、不占档位三限制预算;
**手做链必须通**(家常样本集基线),手工产出无增益或极弱增益(gains-nutrition.md)。
陶罐为**纯前期道具**,电力时代由烹饪工坊/酿窖完全替代(food-processing.md §手工炊事载体)。
