# 机器体系(Machines):多方块优先

> **状态:方向已定案 / 结构细则待收口** — 2026-09-09
>
> 原则 7(overview.md):**零新增套皮单方块机器**。单方块能力一律并入多方块;
> 复用 GTCEu 既有机型不受此限(复用不是套皮)。全跨度新增多方块 **17 台**,新增单方块 0 台;
> 顶档 UV–UIV 不设机器(元素级合成复用 GT 装配线/反应器),稀疏语法不破。

### 后续候选(未立项,防拍脑袋)

气调保鲜仓(IV,若从中央厨房模块拆出)、净菜处理线(HV)、风味合成塔(UHV,若顶档决定机器化)。
立项门槛照三问+三限制。

## 2. 手工层(工具与交互方块,非机器)

菜刀/削皮刀/研钵/擀面杖等耐久工具组,以及**陶罐**(篝火炖煮/常温发酵交互方块,
见 food-processing.md §手工炊事载体)——均不属机器,不进本表、不占档位三限制预算;
**手做链必须通**(家常样本集基线),手工产出无增益或极弱增益(gains-nutrition.md)。
陶罐为**纯前期道具**,电力时代由家厨工坊完全替代(food-processing.md §手工炊事载体)。

## 4. 结构与仓室需求(草案,结构细则逐台定案)

- 复用 GT 仓室体系(能源仓/流体仓/物品仓);高档模式下仓室可用到 MAX(tier-map.md §1);
- 特殊仓室候选:温室气候仓、畜牧工坊畜栏接口、编译器菜谱输入仓——**仅当多方块叙事必需时立项**,
  同样受"多方块优先"约束(仓室不是单方块机器);
- 每台多方块的验收清单(结构/配方/并行/信息显示)随实装批次写入本文档 §5(逐台追加)。
