# 机器体系(Machines):多方块优先

> **状态:方向已定案 / 结构细则待收口** — 2026-09-09
>
> 原则 7/11(overview.md):**零新增套皮单方块机器**;**单一用途**——一台多方块只承载一类工艺用途,
> 用途拆分优先于功能合并(家厨工坊已拆分为切配工坊+烹饪工坊),同用途的量产上位不算新用途;
> **例外**:时间转化类工艺(固态发酵/熟成/酒陈酿)同仓模块化为「酿窖」——它们的共同本质是"时间+环境控制";
> **不新增生物**——新动物源产品一律经养殖场多方块虚空生成(镜像姊妹项目采矿厂/钻井语法)。
> 复用 GTCEu 既有机型不受此限(复用不是套皮)。全跨度新增多方块 **22 台**,新增单方块 0 台、新实体 0 个;
> 顶档仅 UV 设元素膳造厂一台(营养闭合专属旗舰,无条件注册);分子料理编译器(OpV)与造粮机(MAX)
> 为**高档门控注册**(检测 `GTCEuAPI.isHighTier()`,tier-map §2);UHV–UIV 不设机器,稀疏语法不破。
> **结构化模块**:一切模块均为多方块本体的**额外结构段**(方块直接砌入,可扩建/拆除),
> 不存在外挂部件或插入式模块物品——通则见 §5.0。

## 5. 逐台规格(随实装批次追加)

### 5.0 模块化通则(适用于一切模块化多方块)

1. **模块=结构段**:模块以方块形式直接砌入多方块本体,是结构的"额外结构段"——可随扩建追加、
   随拆除回收;**不存在外挂部件或插入式模块物品**;
2. **配方门槛=结构**:配方绑定所属模块段,结构中未建该段则配方不可运行(EMI/Jade 明示缺哪段);
3. **段数=并行**:每个模块段独立执行一份配方,多建有真实回报;
4. **增量交付**:基础结构+任意段组合即可运行,模块段可跨批次交付;
5. 同用途的段位扩展不算新用途(原则 7)。

### 5.1 切配工坊(LV)

| 结构段 | 承载 |
| --- | --- |
| 刀工段 | 切片/切丝/切块(编程电路选择) |
| 绞碎段 | 绞肉/剁馅 |
| 研磨段 | 香料现磨段:香料/干料现磨(品位保真;谷物制粉归大型磨坊,§5.4) |
| 剥皮段 | 削皮 |
| 压延段 | 面条/面皮 |

### 5.2 烹饪工坊(LV)

| 结构段 | 承载 |
| --- | --- |
| 煮段 | 汤/煮制/巴氏杀菌低温档 |
| 蒸柜段 | 蒸制 |
| 炒灶段 | 炒制(油类 LV 后) |
| 炸锅段 | 油炸 |

### 5.3 隧道烤炉(MV)

**结构组成**:基础机架(控制器+输入/输出仓+能源仓+输送段)+ 炉温段模块。

| 炉温段模块 | 温度带(真实烘焙对照) | 解锁配方示例 |
| --- | --- | --- |
| 低温段 | 120–160 °C | 果干、烘干、低温慢烤 |
| 中温段 | 170–190 °C | 面包、蛋糕、饼干、酥皮 |
| 高温段 | 210–250 °C | 披萨、硬壳上色、高温快烤 |

烤炉专属规则:**强制预热**——冷机启动需预热时间(段数越多越长),连续生产才是正解(呼应"隧道"叙事)。

### 5.4 中央处理厂(IV)

切配工坊/大型磨坊/分割产线的**集中量产上位**:三条产线作为结构段砌入同一大型多方块
(切配线/制粉线/分割线),段语法沿用 §5.0(段=结构、配方门槛=结构、段数=并行)。
价值=原料处理物流中枢(净菜/面粉/分割肉一站式大吞吐);三台小机器保留为 LV–HV 可达路径与
低吞吐场景选项(GT 单方块与多方块并存的常态,不作功能性删除)。

### 5.5 元素膳造厂(UV)

营养闭合的专属旗舰:输入 GT 装配线/生物反应器产出的通用蛋白质/氨基酸/维生素,
装配为合成配料与纯合成菜(配方复用装配线配方类型的 UV 段或自建 `element_diet` 类型,实装定案)。
UV 菜单市场(纯合成菜矩阵)由此承载;UHV 起的风味/质构/缓释配料仍走 GT 复用机型。

### 后续候选(未立项,防拍脑袋)

净菜处理线(HV)、风味合成塔(UHV,若顶档决定机器化)、藻类光反应器(EV,若从生物反应器拆出)。
立项门槛照三问+三限制+单一用途。

## 2. 手工层(工具与交互方块,非机器)

菜刀/削皮刀/研钵/擀面杖等耐久工具组,以及**陶罐**(篝火炖煮/常温发酵交互方块,
见 food-processing.md §手工炊事载体)——均不属机器,不进本表、不占档位三限制预算;
**手做链必须通**(家常样本集基线),手工产出无增益或极弱增益(gains-nutrition.md)。
陶罐为**纯前期道具**,电力时代由烹饪工坊/酿窖完全替代(food-processing.md §手工炊事载体)。

## 4. 结构与仓室需求(草案,结构细则逐台定案)

- 复用 GT 仓室体系(能源仓/流体仓/物品仓);高档模式下仓室可用到 MAX(tier-map.md §1);
- 特殊仓室候选:温室气候仓、畜牧工坊畜栏接口、编译器菜谱输入仓——**仅当多方块叙事必需时立项**,
  同样受"多方块优先"约束(仓室不是单方块机器);
- 每台多方块的验收清单(结构/配方/并行/信息显示)随实装批次写入本文档 §5(逐台追加)。
