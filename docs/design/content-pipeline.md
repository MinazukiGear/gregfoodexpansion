## 1. 内容即数据

- 内容增删改 = **数据表 PR + lint 通过**,不产生散文决议文档;
- 设计文档只存**规则**(判据/闸门/语法),内容清单一律入表;
- 表的权威存放(已定案):`src/main/resources/content/`,版本控制同代码;
  datagen 经 `--existing src/main/resources` 读取,lint/贴图管线直接读文件系统。

## 2. 核心表 schema

### 2.1 作物表(crops)

```
id / 类别 / 环境参数(温·湿·光) / 工业归属(类别链模板 + 单品签名) /
品位维度(§维度表) / 配色主题 / 批次 / 来源(真实性)
```

### 2.2 组合表(matrix,每模板一张)

```
菜名(中/英) / 别名(同菜异名) / 主料 / 辅料 / 味型(B2 引用) /
工艺序列 / 品质轨(基础/精制/合成) / 来源(三级) / 变体标注 / 批次
```

### 2.3 菜谱登记表(registry,B 群)

```
菜名(中/英) / 菜系 / 签名等级(旗舰/标准/中间品) / 配料链 / 工艺序列 /
独家权益 / 天然门槛标注 / 品位响应 / 来源(三级) / 贴图等级(手绘/AI精修/合成) / 批次
```

辅助表(首版已定案):味型表 `flavors/`(B2 复合味型/中间品,kind 区分)、加工基料表
`ingredients/`、动物源分割表 `animals/`(产物带 via 最早工艺)、原版接链表 `vanilla-links/`
(随 M1' 首批实装)、工艺总表 `processes.json`(food-processing.md §3 的机器可读镜像,
工艺=最早可达档位)、家常样本集 `samples/`(菜名+配料依赖+工艺,可达率审计输入)、
机器总表 `machines/`(machines.md §1 的表化:id/中英名/档位/单一用途,驱动机器语言生成);
配料引用语法:`crop:<id>` / `b2:<id>` / `base:<id>` / `animal:<id>` / `vanilla:<id>`。

## 3. datagen 管线

表 → datagen 一键生成:物品/方块注册、模型与 blockstate、配方(工作台手做档 + 多方块机器档)、
语言(三语零差集)、战利品、标签(forge 通用语义/forge 形态/模组内部三层)、图鉴数据。

## 4. 贴图管线

| 管线 | 用途 | 人工介入 |
| --- | --- | --- |
| 模板调色 | 作物生长期(禾本科/叶菜/果菜/藤蔓/菌菇/水生骨架模板) | 配色审核 |
| 分层合成 | 菜肴(基底库:碗/盘/签/杯/瓶/罐 × 内容物调色层) | 抽检 |
| AI 底稿+精修 | B1 标准级专属贴图 | 精修必做 |
| 全手绘 | B1 旗舰级、多方块机器贴图 | 全程 |

> 模板由任务自动生成于 `src/templates/`(非发布资源),正式手绘模板同路径覆盖。

基底库 ~20 基底起步,随模板池扩容;旧版 267 张贴图已删除,资产从零按管线重建(模板先行)。

## 5. 内容 lint 全清单(构建期断言,违反即失败)

> 实装(2026-09-12):`gradlew contentLint` 挂接 `check` 与 `runData`,错误级使构建失败;
> 报告落盘 `build/reports/content-lint.txt`(UTF-8)。严重级按规则原文动词映射:
> "拒绝/构建失败"= 错误(1/2/3/4/8/9),"报缺口/报警"= 警告(5/6/7/10)。

1. 作物无工业归属(三票制)→ 拒绝注册;
2. 菜肴无来源字段/来源等级不足 → 构建失败;
3. 配料不在宇宙内 → 拒绝生成;
4. 同一组合表内存在品位维度完全相同的两种配料 → 拒绝(维度轴 = §2.1 维度表细粒度子轴);
5. 每档位无基础可达菜(钥匙制验收)→ 报缺口;
6. 家常样本集可达率 < 门槛(第一批 ≥50%/目标 75%)→ 报缺口作物;
7. 配料冗余 <3× / 组合覆盖率异常 → 报警;
8. 增益越过天花板档 → 拒绝(登记行 gainTier 字段;增益管线随 M1' 补全后接自动计算值);
9. zh/en/ud 语言条目差集 ≠ 0 → 构建失败(en_ud 由 en_us 颠倒翻转,原版内置语言);
10. 同菜异名未合并(同源同名变体)→ 报警。

## 6. 数量判据(cuisine-matrix.md §6 的治理化)

- 配料冗余 ≥3×;杠杆曲线监控(菜:作物 ≈ 1:10~1:13 为健康带);
- 同菜异名合并计数;300 作物时执行品位维度去重审计(扩容触发条件)。

## 7. 贴图吞吐预算(速度瓶颈的诚实声明)

作物 6~8 张/种、菜肴按贴图等级 0.2~1 张/道;300+ 作物 ≈ 2,000~3,500 张——
分批数年消化,批次规模 = 管线吞吐,不是设计上限。

## 8. 文档与难度治理

- 状态标注制(方向已定案/数值待收口/已实装)+ 收口制(实装前逐项定案回写);
- 难度声明制:新数值标注是否受难度控制,未声明视为三档一致(gains-nutrition.md §4);
- 社区提交规则:数据表 PR + 真实性来源必填 + lint 全闸(与内部同标准)。
