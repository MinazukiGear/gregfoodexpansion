# 食材处理与配料宇宙(Food Processing & Ingredient Universe)

> **状态:方向已定案 / 数值待收口** — 2026-09-09
>
> 三问自检:① 消费方=菜肴矩阵(B2 反哺)+动物饲料;② 每把工艺钥匙给新配料维度;
> ③ 卡点=配料宇宙是菜单矩阵与品位轴的公共底座。

## 1. 配料宇宙四层

| 层 | 规模(终局) | 来源 |
| --- | --- | --- |
| 作物系配料 | ~900+ | 每作物 3~6 配料(主产物/切片/切丝/腌渍/油/粉),按类别链模板派生 |
| 动物系配料 | ~100~120 | livestock.md(饱和,不扩) |
| B2 味型/中间品 | ~300~400 | signature-cuisine.md(味型汁/浇头/汤底/皮坯/卤料包) |
| 加工基料 | ~40 | 面团系(死面/发面/酥皮/糖浆皮/米粉皮/澄粉)、油脂、酵母/菌种、高汤 |

合计终局 ~1,300~1,500 条;对 3,500~4,000 道菜保持 **配料冗余 ≥3×**(cuisine-matrix.md §6)。

## 2. 处理原则(收编旧版"合理处理原则")

1. **真实处理**:处理方式必须有真实烹饪依据(切配六式/压延/腌制/磨浆/榨汁/干制/泡发);
   不为物品数发明处理方式;
2. **生熟分品**:合理处理含生熟维度(熟鸡可切丝,生鸡不可);
3. **同名多轨**:同一菜名空间下,基础/精制/合成三轨配料各成物品(SoL 独立计数,意义存续);
4. **入宇宙即有归宿**:lint 保证每种配料至少出现在一张组合表或一个菜谱登记行。

## 3. 工艺总表(处理侧工艺钥匙)

| 工艺 | 载体 | 档位 | 产出 |
| --- | --- | --- | --- |
| 切配六式(切片/切丝/切块/绞碎/**香料现磨**/剥皮)+压延 | 切配工坊 | LV | 形态配料、面条/面皮(香料现磨品位保真;谷物制粉归大型磨坊) |
| 磨浆/榨汁/榨油/熬油 | 切配工坊 + GT 提取机 | LV(**油类全部电力时代后,手工层无油**) | 豆浆/果汁/食用油;动物油脂(肥膘→猪油,牛油固+液双形态) |
| 烘焙(基础) | 烹饪工坊·烤模式 | LV | 面包族(量产升级=隧道烤炉,MV) |
| 腌制 | 酿窖·固态发酵模块 | HV | 咸蛋/皮蛋/腌肉/泡菜 |
| 巴氏杀菌 | 烹饪工坊·煮模式低温档 | MV | 巴氏奶(配方门槛) |
| 酶解/糖化 | GT 化学反应釜+酶 | HV | 高出成糖化 |
| 冻干 | GT 真空冷冻机 | HV | 速食/脆片 |
| 气调包装 | 中央厨房模块 | IV | 预制菜/远征口粮 |
| HPP 冷杀菌 | (ZPM 工艺,载体待定案) | ZPM | 全效保留版 |

手工层(工作台刀具组:菜刀/削皮刀/研钵/擀面杖)保持可达——**手做链必须通**,手做菜即家常样本集
基线(约 50 道,名录初稿 51 行);手工产出无增益或极弱增益(gains-nutrition.md)。

**手工层边界(2026-09-09 定案,防反复)**:

1. **不收编炒锅/蒸笼**——手工炊事 = 工作台拼装 + 篝火/熔炉烤制 + 陶罐炖煮;蒸/炒/炸精确工艺属烹饪工坊(LV 起),腌渍属酿窖(HV 起);
2. **所有油类均在电力时代后**——油脂不入手工层(否决熔炉炼猪油/手工榨油路线);
   油类产线 = 切配工坊/GT 提取机(LV 起;提取机先例:种子油/鱼油);
3. **手工可达率不设量化指标**——家常样本集审计不含此项,手做定位 = 过渡与多样性基线。

**手工炊事载体(2026-09-09 定案:陶罐)**:

| 载体 | 承担 | 语义 |
| --- | --- | --- |
| 工作台 | 冷拼/卷饼拼装、刀具使用 | 纯物品 |
| 篝火/熔炉 | 单料烤制、串类(手工木签) | 单物品输入 |
| **陶罐** | 多料炖煮(粥/汤/水煮)+ 常温发酵(泡菜/浊米酒) | 4 格投料,交互方块 |

- **陶罐不是机器**:无 GT 配方类型、无电压、不占档位三限制预算,与刀具组同类(手工交互方块);
- 规格:陶土塑坯+熔炉烧制;仅放置于点燃篝火正上方工作;右键投料自动匹配配方;空碗/空瓶取餐
  (一锅 2~4 份,吃完返碗,罐不消耗);
- **双模式**:篝火加热 = 炖煮(分钟级);常温放置 = 发酵(游戏日级,时间语义由方块实体承载);
- **配方类型**:自建 `clay_pot_cooking`(原版配方系统),数据表驱动,即组合表的"手做轨";
- **升级线**:陶罐是**纯前期道具**——其全部配方(炖煮+发酵)在电力时代由烹饪工坊/酿窖**完全替代**
  (每道陶罐菜均有对应机器配方,增益与并行归机器);LV 后陶罐仅余装饰/收藏价值,不作功能性保留。
  意义存续原则约束的是作物与菜肴资产(菜肴经精制轨终身有效),工具类允许正常晋级淘汰。

**手工流体桥(2026-09-09 定案)**:流体不接 GT 网络,走容器物品——
「一碗水」(空碗右键水源,≈250 mB 语义;熟制后食物装碗、吃完返碗,蘑菇煲先例)、
原版水瓶(饮品,喝完返瓶)、原版牛奶桶(备用奶源,蛋糕返桶先例)。
不实现 `IFluidHandlerItem`(手做层纯物品语义;通用流体容器待真有跨机需求再议)。
电力侧同菜精制版走真实流体配方,与手做桥互不引用。

## 4. 品位挂钩

配料品位随来源登记:作物品位(crops.md §3)、饲养品位(livestock.md §6)、
**处理品位**(加工损耗/精度:酶解 > 酸解,冷榨 > 热榨——工艺钥匙同时是品位工具)。

## 5. 机器承载

处理工艺全部由多方块或 GT 复用机型承载,零新增单方块(machines.md);
切配工坊承接旧切配机全部职责,烹饪工坊承接旧通用烹饪机全部职责(单一用途,machines.md)。
