# 饮品线专项设计(Beverage Chain)

> **状态:已定案(轮廓)** — 2026-09-07
>
> 七项骨架决议(Q1–Q7)经讨论落定;烘焙/萃取/碳酸化机器指认、饮品增益效果表等细节在遗留清单(§9)。

## 1. 定位与动因(决议 Q1)

支柱 E 的工业化落地。动因三项,**与罐头线口径对齐**:

1. **SoL 多样性平行清单**:每款饮品为玻璃瓶装独立 SKU,计入多样性统计;
2. **即时增益载体**:咖啡因/茶多酚等功能款,增益**即饮即耗,不做"时空转移"**(与罐头线同红线);
3. **工业叙事**:农产品升值链的液体端。

~~探索补给~~ 并入 3,不单独立项(与罐头物流密度动因重叠)。

## 2. 容器与灌装(决议 Q2)

- **复用原版玻璃瓶**(蜂蜜瓶/药水瓶容器先例,零新增容器物品);
- 饮品 = 玻璃瓶装独立 SKU;灌装 = **装罐机静态配方**,照抄罐头线模式(`CANNER_RECIPES` IO 2/2/1/1:流体饮品 + 玻璃瓶 → 瓶装饮品,足够);
- 不做耐压罐装叙事(碳酸同样走玻璃瓶);
- 风险标注(实现期):空瓶回收配方与药水/蜂蜜配方池共用玻璃瓶,配方注册注意不去动原版条目;分拣按物品本体无 NBT 歧义。

## 3. 果汁链(决议 Q3)

- 单元操作:压榨(提取机)→ 澄清(离心机/化学釜)→ **原榨汁**;
- 浓缩还原:浓缩(蒸馏室三档 2×/4×/8×,乳品决议 3 白捡)→ 浓缩汁(可箱运,物流密度)→ 复原(配水)→ **浓缩还原版**;
- **双版本限大宗果**(葡萄/苹果/柑橘/菠萝等,随作物批次登记),小众果仅原榨;
- 果汁 → 果酒 = 发酵交接面(支柱 D 承接)。

## 4. 碳酸饮料(决议 Q4、Q7)

- **CO₂ 回收闭环**:发酵槽/酿酒机配方挂副产 CO₂(GTCEu `carbon_dioxide` 已存在,发酵生物质分馏产出先例 `DistillationRecipes.java:112-121`);
- 碳酸化工序机器待指认(候选:化学反应釜合成汽水浆 / 装罐机直接碳酸灌装);
- SKU:**气泡水**(水 + CO₂,兼灌装线最简基准配方,决议 Q7)、**柠檬汽水**(糖浆 + CO₂,P1 柑橘);
- **可乐按"池→批跳队条款"等青柠进批再立项**,不得用柠檬替代(不预支长尾池价值);调味汽水随作物批次滚动注册(合理处理原则)。

## 5. 咖啡与茶饮(决议 Q5:两档制,SKU 不设硬上限)

### 咖啡

剥皮(切配机电路 6)→ 生豆 → **烘焙两档**(浅焙=果酸调/精品线基;深焙=苦香调/意式拿铁基)→ 研磨(电路 5)→ 萃取 → 咖啡液。

- SKU:黑咖啡(深焙基)、拿铁(咖啡液+乳品流体奶)、冰咖啡(浅焙基+冰,真空冷冻机副产);
- **M4 耦合**:育种"有效成分含量(咖啡因)"作用于萃取出成率——两档制是首个表达位;
- 咖啡因 GT 化工两用(首批作物归属表),提纯路线留支柱 D/M3+;
- 烘焙、萃取机器指认待定(§9)。

### 茶

鲜叶两路:**绿茶** = 杀青(流体加热器/烹饪机蒸)→ 揉捻(切配机压延/绞碎)→ 干茶;**红茶** = 萎凋揉捻 + **氧化发酵(发酵槽**,M0 已证配方空间空白,又一复用点**)**→ 干茶;冲泡 = 热水萃取。

- SKU:绿茶、红茶、**奶茶**(红茶+乳品流体奶,**归饮品线**,液体灌装);柠檬茶等调味款随 P1 柑橘滚动;
- 抹茶 = 绿茶研磨分支,归**食材形态层**,不算饮品 SKU;**珍珠奶茶维持彩蛋级**(木薯 P2 进批后加珍珠);
- **SKU 不设硬上限**:新调味款按合理处理原则滚动注册,与作物清单"活文档"治理同构。

## 6. 酒类边界(决议 Q6)

本专项**只定非酒精饮品**;果汁→果酒、麦芽→啤酒由支柱 D 承接(M1 里程碑已排);蒸馏酒(威士忌/白酒/白兰地)归 M3 深水区,挂蒸馏塔;酒醉效果维持低优先级彩蛋。

## 7. 增益定位

功能款饮品按 [dishes-and-gains](dishes-and-gains.md) 增益框架纳入精制档;具体效果与品质档定位**与 packaging-and-canning §11.2-1(罐头品质档)一并回补**。

## 8. 电压映射(定性,数值待定案)

压榨/原榨 = LV;浓缩还原、碳酸化 = MV(§8);咖啡烘焙/萃取 = LV/MV;冰咖啡用冰 = 真空冷冻机档位;巧克力饮品随可可链(P2)。
