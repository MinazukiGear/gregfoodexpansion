# 发酵与食品生物化学深水区(Biochem Chain)

> **状态:已定案(轮廓)** — 2026-09-07
>
> 五项决议(Q1–Q5)落定;耐久催化 API 确认、味精加成数值等细节在遗留清单(§7)。酱油/酸奶/泡菜/酒已由前序专项与里程碑收口,本专项不重复。

## 1. 定位与范围

支柱 D 深水区(M3):**味精链、柠檬酸双路线、酶制剂家族、酿造醋**。电压表定位:HV = 味精/柠檬酸发酵、酶制剂;糖化自 MV 起(酸解路线);酿造醋 MV。

**横向机制承接**:谷氨酸/柠檬酸/产酶发酵全部挂**菌种自举横向机制**(乳品决议 7:简易 M2 复用大豆线,纯培养 HV+ 借琼脂/细菌/洁净室);发酵载体 = 发酵槽(M0 已证配方空间空白)与酿造房 Brewery(并行)。

## 2. 味精链(决议 Q1、Q4)

玉米 → 淀粉(已有归属)→ **糖化** → 葡萄糖 → **谷氨酸发酵**(葡萄糖 + 氨 + 菌种,HV;氨全链 M0 已证)→ 谷氨酸 → **中和**(氢氧化钠,`FirstDegreeMaterials.java:1022`)→ 味精。

### 2.1 糖化双路线(决议 Q1)

> 2026-09-08:**酸解路线 M1 版已实装**(淀粉×2+水+盐酸→葡萄糖×2,MV,低出成;
> [starch-chain](starch-chain.md) §1,上游湿磨取淀粉同日落地)。酶解路线仍留本节 M3。

| 路线 | 配方 | 电压 | 定位 |
| --- | --- | --- | --- |
| 酸解 | 淀粉 + 盐酸,化学反应釜,低产出,副产氯化物可回收 | MV | 低电压凑合路线 |
| 酶解 | 淀粉 + 糖化酶(耐久催化),高出成 | HV | 效率路线,酶制剂稳定消费点 |

### 2.2 味精终端用途(决议 Q4)

**提鲜投入品**:部分精制菜肴/罐头配方可选投入味精,增益**时长**小幅加成。边界(数值克制):

- **可选投入**——不放味精配方照常成立,只是增益短一截;
- **只加时长,不加成效果强度**——不碰增益种类与等级;
- 与 SoL 多样性乘数、品质档两套数值**相互独立**;
- 具体幅度随增益表回补定(dishes-and-gains 回补同批)。

## 3. 柠檬酸(决议 Q2)

**双路线落地**:

- 天然提取:柑橘压榨/离心副产(P1 柑橘),MV,低产出;
- 发酵合成:葡萄糖 + 菌种,发酵槽,HV,高产出。

**用途边界**:只做**食品酸味剂**(饮品/罐头/糖果);**化工两用挂"待查证提升"**——本次查证 GTCEu 无柠檬酸下游接点,不预设自建用途,查到真实接点再立项(镜像青柠跳队条款治理,避免空动因)。

## 4. 酶制剂家族(决议 Q3)

**产酶**:HV+ 微生物发酵(菌种 + 培养基,发酵槽/反应釜)。

**消耗模型 = 耐久催化剂**:酶为带耐久的催化物品,配方每次执行扣耐久、耗尽损坏(镜像成型压机非消耗模具机制)。实现期需确认 GTCEu 配方 API 支持度;**若不支持则整体回退消耗品模式,不做混合模型**(规则分裂)。叙事与平衡收益:"微量高效"、酶贵但摊薄、HV 配方不被 dust 成本绑架。

**家族清单与生效线**:

| 酶 | 生效线 | 效果 |
| --- | --- | --- |
| 糖化酶 | 味精链 | 淀粉酶解高出成(§2.1) |
| 果胶酶 | 饮品线 | 果汁澄清出成提升(回补 beverage-chain) |
| 凝乳酶 | 乳品线 | 已在乳品新增清单 |
| 木瓜蛋白酶 | 肉品线 | 长尾跳队条款(嫩化) |

**设计原则**:酶 = 效率开关——不用酶可做(低出成),用酶高出成;不设"必须用酶"的硬门槛配方。

## 5. 酿造醋(决议 Q5)

- **新增食品物品"酿造醋"**,发酵路线:乙醇 + 醋酸菌(氧化发酵,发酵槽,MV);
- 与化工乙酸(已存在,`DistillationRecipes.java:54/109` 等多条产出)**并行不混同**——食品级 vs 化工级双叙事,与明胶/gelatin、柠檬酸双路线同构;
- 用途:泡菜/调味/酱汁基底(泡菜 M1 配方对接)。

## 6. 电压映射(定性,数值待定案)
