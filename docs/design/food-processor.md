# 切配机(Food Processor)

> **本文档记录 GregFood Expansion 切配机(食材预处理,单方块)及其手工工具组的当前设计。** 这里的数值是后续实现、平衡测试与配方注册的基准;讨论决议标注 **[已定案]**,本文新增细节标注 **[草案]**,经审核后改为已定案。尚未定案的内容集中列在文末。
>
> 决议来源:2026-09-07 专项讨论(补入食材处理层的立项)——切配机命名、六式刀工+压延、2/2 无流体 IO、面食并入、手工工具多样化、预算直接追加、两条边界。

## 1. 定位与范围

**定位**:作物/胴体产物与烹饪机之间的**食材形态层**。烹饪配方需要的是肉片、蒜末、番茄丁,而非整只原料——本机把原料变换为形态食材,与通用烹饪机构成第二组"工业机器 ↔ 手工耐久工具"配对(切配机 ↔ 菜刀组)。

**非目标**:腌制/烟熏(支柱 C 专项);食品配方进 GT 粉碎机/切割机(边界,§8);独立面条机(已并入本机,决议)。

| 机器 id | `food_processor`,中文"切配机" |

## 3. 刀工操作与编程电路 [已定案]

与通用烹饪机同构:机器无模式状态,配方自带 `gtceu:programmed_circuit`(`notConsumable`)区分操作。

| 电路配置 | 操作 | 说明 |
| --- | --- | --- |
| 1 | 切片 | 片状食材、肉片 |
| 2 | 切丝 | 丝状食材 |
| 3 | 切块 | 丁/块(薯条坯、番茄丁) |
| 4 | 绞碎 | 肉馅、蒜末、洋葱末 |
| 5 | 研磨 | 香料粉、辣椒粉 |
| 6 | 剥皮 | 果肉/去皮蔬菜 |
| 7 | 压延 | **面食并入**(面团→面条/面皮,米粉→米粉)——原"面条机"职责,决议撤销独立面条机 |
| 8 | 预留 | 不分配用途 |

绞碎/切片同时为支柱 C 屠宰分割(胴体→各肉种切片/肉馅/碎料,按种类区分)预留入口,肉品专项直接复用本机。

## 4. 配方体系 [类型与 IO 已定案,形态草案]

**IO 规格 [已定案]**:物品输入 ×2、物品输出 ×2,**无流体**。输出第二槽放边角料(切丁边角→碎菜/碎肉,概率),边角料可回流绞碎,形成小循环。

| 食材 | 操作 | 产物(示例) |
| --- | --- | --- |
| 马铃薯 | 切块 | 薯条坯 |
| 番茄 | 切块 | 番茄丁 |
| 洋葱/大蒜 | 绞碎 | 洋葱末/蒜末 |
| 辣椒 | 切片/研磨 | 辣椒圈/辣椒粉 |
| 生肉(按种类区分,决议) | 切片/切丝/切块/绞碎 | 牛肉片/猪肉丝/鸡肉丁/猪肉馅等——各肉种独立单品,组合以合理性门控 |
| 面团 | 压延 | 面皮/面条 |
| 米粉团 | 压延 | 米粉 |
| 水果 | 剥皮 | 果肉 |

- 名录按**合理处理原则**扩展(决议:合理即注册、不合理拒绝,不做数量预算约束):具体形态名录见 [dishes-and-gains.md](dishes-and-gains.md) §4;
- 压延配方需要作物基座产出的面团/米粉团(见 [作物系统基座](crop-system-foundation.md))。

## 5. 数值基准 [草案,实机调参]

| 项 | 数值 |
| --- | --- |
| EU/t | 4–8(压延取上限) |
| 时长 | 40–100 tick(压延 60–100) |
| 电压门控 | 无;ULV 可用,全 tier 靠 overclock 提速 |

预处理定位为高频小配方:低 EU、短时长,量产压力由多方块阶段吞吐解决(中央厨房不并行本类型,保持切配的独立机器定位)。

## 6. 品质 [已定案]

**食材(中间品)不带品质档**。品质由终端菜肴的产出机器决定(通用烹饪机/中央厨房 = 精制档);中间层不标记,避免档位扩散。

## 7. 手工工具组 [多样化已定案,清单草案]

工作台 + 工具(耐久消耗,不消耗本体)= 手工切配,配方刻意少,LV 后由机器接管。工具均为 vanilla 工具机制、铁质起步:

| 工具 | id | 覆盖操作 |
| --- | --- | --- |
| 菜刀 | `cleaver` | 切片/切丝/切块/绞碎 |
| 削皮刀 | `peeler` | 剥皮 |
| 研钵 | `mortar_pestle` | 研磨 |
| 擀面杖 | `rolling_pin` | 压延(手工面皮/面条) |

工具集可随批次增长(材质升级、专用刀具),后续新增不推翻本表结构。手工烹饪侧工具组为厨刀/炒锅/蒸笼(见 [通用烹饪机 §7](universal-cooker.md)),两组工具语义互不重叠。

## 8. 边界 [已定案]

1. **食品配方不进 GT 粉碎机/切割机**:粉碎机输出粉尘、切割机用锯刃,与"丝/片/馅"的食物形态语义不符;保持食品线配方可读性;
2. **食材不带品质档**(§6);
3. 压延面食不单独立机(§3,决议)。
