# 作物体系(Crops)

> **状态:方向已定案 / 数值待收口** — 2026-09-09
>
> 三问自检:① 消费方=食材处理层+动物饲料(工厂)+餐桌(玩家);② 每批作物带来新的配料维度与品位维度;
> ③ 卡点=饲料品位闭环与生物质咬合(crops↔livestock↔gt-interlocks)。

## 1. 作物系统架构

- **作物实体**:标准农田作物(播种/生长/收获),实体携带**环境参数**(温度·湿度·光照,为温室水耕预留)
  与**品位字段**(有效成分含量,育种轴起点);
- **野生作物**:同实体野生变体,世界生成,提供开局种子与育种杂交素材;
- **原版接链**:原版作物不加实体,只补工业链与配料(§5)——与"零作物成本"批次同步;
- **温室**(machines.md):配方式催熟+气候偏差成本模型;大型温室(IV)全参数气候+水耕。

## 2. 三票制(入池闸门,防注水)

每个候选作物必须同时具备:

1. **工业归属**:至少一条加工链(配料→半成品→终端),按类别链模板派生 + 单品签名(招牌产品);
2. **环境参数**:温度·湿度·光照至少一项有辨识度(温室价值);
3. **品位维度**:绑定至少一个有效成分维度(§3),参与育种轴。

真实性同闸:候选池只收**有农业史的真实植物**;来源与作物表登记见 content-pipeline.md。

## 3. 品位维度表(防 interchangeable 的承重机制)

| 类别 | 有效成分维度(品位轴) | 终点用途 |
| --- | --- | --- |
| 谷物 | 淀粉含量、麸质/蛋白含量 | 出成率、面皮筋度(成型家族门槛) |
| 果蔬 | 糖度、酸度、果胶 | 果酱/饮品/质构 |
| 香料 | **风味强度**(辣素/精油/呈味) | 味型 B2 品质、独家增益触发 |
| 油料 | 含油率、脂肪酸谱 | 出油率、煎炸工艺门槛 |
| 豆类 | 蛋白含量 | 豆制品出成率、培养蛋白竞品 |
| 饮品作物 | 咖啡因、茶多酚 | 饮品增益、GT 化工两用 |

规则:两种作物若**维度完全相同**则拒绝同时进入同一张组合表(lint)——300+ 作物规模时的
**维度去重审计**是扩容触发条件(content-pipeline.md §7)。

## 4. 第一批:家常覆盖批(已冻结,~46 实体 + ~11 原版链)

选批原则:**日常菜肴覆盖率 ≥50%,目标 75%**(家常菜样本集审计,cuisine-matrix.md §5)。
家常菜的"操作系统"是葱、姜、蒜、辣、花椒——必须第一批到位。

### 4.1 继承层(旧版已实现概念,资产随管线重建)

大豆、玉米、水稻、大麦、花生、番茄、洋葱、辣椒、白菜、葡萄、咖啡、茶、啤酒花。

### 4.2 家常缺口层(18)

大蒜、生姜、大葱、韭菜、菠菜、生菜、黄瓜、茄子、芹菜、白萝卜、豌豆、蚕豆(豆瓣酱)、
香菇、芝麻、香蕉、草莓、柑橘、彩蛋:香菜(爱恨彩蛋)。

### 4.3 杠杆追加层(15)

糯稻(成型家族皮坯)、红豆(豆沙馅)、绿豆(豆芽/粉丝)、竹笋、木耳、木薯(珍珠奶茶)、
红薯(淀粉第二源)、肉桂、八角(卤料包 B2)、胡椒、小米、桃、菠萝(菠萝蛋白酶→GT 酶两用)、
芋头、油菜(菜籽油)。

### 4.4 原版接链(11,零作物成本)

小麦、土豆、胡萝卜、甜菜、甘蔗、可可、南瓜、苹果、海带、甜浆果、蜂蜜(原版蜂巢)。

### 4.5 第一批配套(动物侧,见 livestock.md)

原版五肉种基础分割、鸡蛋+咸蛋黄链、乳系基础 SKU、**新动物仅鸭**(咸蛋/皮蛋/烤鸭刚需)。

## 5. 候选池分层(开放终态,真实性封顶)

| 层 | 规模 | 内容 | 驱动 |
| --- | --- | --- | --- |
| 核心层 | 累计 ~150 | 旧长尾池清算:水果 24、油料坚果 10、香料 11、蔬菜根茎 8、谷物 7、水生 5、豆类 5、花饮 3、菌菇/工业/终局 3 | 菜系包第一轮 + lint 缺口 |
| 菜系扩展层 | 累计 ~250~300 | 世界香料(孜然/豆蔻/茴香/莳萝/咖喱叶/香兰叶…)、世界水果(山竹/龙眼/菠萝蜜/椰枣…)、世界叶菜根茎、豆类坚果、菌菇家族、油料糖料(油茶/枫糖)、饮品作物(马黛/路易波士/菊苣)、水生海藻(紫菜/裙带菜) | 南洋/中东/印度/拉美/地中海/东欧菜系包 |
| 深度层 | 350~500(开放终态) | 小众真实植物 | 社区按同规则提交(来源必填,lint 照闸) |

**入库由菜单需求拉动**:组合表 lint 的缺口报告("第 N 行需要 X 配料,宇宙不存在")是下一批作物的
选题来源——供给被需求拉齐,不出现"有原料无去处"。

## 6. 育种路线(品位轴进度,M4 起分档上线)

| 阶段 | 档位 | 内容 |
| --- | --- | --- |
| 品系记录 | MV(畜牧工坊附带) | 产量/品位数据记录,手工选种(小幅品位提升) |
| 基因纯系与转基因 | IV(**育种实验室**上线) | 品位提纯与大跳变,"作物版矿石品位"机制 |
| 合成生物学菌种 | LuV(育种实验室模块) | 菌种版品位顶点(fermentation-biochem.md) |

天然配料品位由育种+环境+施肥决定,可超合成基准(120%/150%+,上不封顶有平衡预算)——
**终局玩家想拉满增益仍要回头种田**(意义存续)。

## 7. 作物管线(数据驱动,详见 content-pipeline.md)

- **作物数据表字段**:`id / 类别 / 环境参数(温湿光) / 工业归属(类别链模板+签名) / 品位维度 / 配色主题 / 批次`;
- **模板家族**:禾本科/叶菜/果菜/藤蔓/菌菇/水生等骨架模板 × 调色管线,单作物 4~5 生长期 + 2~3 产物贴图;
- **单作物成本目标**:一行数据 + 几张调色图;批次按贴图吞吐排期(每批 25~30 种)。
