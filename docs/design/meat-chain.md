# 肉品线专项设计(Meat Chain)

> **状态:已定案(轮廓)** — 2026-09-07
>
> 六项骨架决议(Q1–Q6)经讨论落定;分割出成率、香肠 SKU、灌制工序机器指认等细节仍在遗留清单(§9),实现期或下一轮专项收口。

## 1. 定位与范围

支柱 C 的肉品半程。**原料 = 原版动物击杀掉落**(决议 Q1:不引入"胴体"中间物品),本线负责从生肉到腌腊/肠类半成品的工业化,熟制与菜肴归通用烹饪机/中央厨房。

**工序分层**(镜像"菜刀组 ↔ 切配机"的手工/工业分层):

| 层 | 承载 | 内容 |
| --- | --- | --- |
| 手工层 | 原版烟熏炉(datapack 配方接入) | 少量烟熏制食品,入门路径 |
| 工业层 | 切配机(电路 8)+ 化学釜/搅拌机 + 后处理厂模块 | 分割、腌制混配、腌制/烟熏时间型工序 |

**非目标**:首版不做屠宰场多方块(留 M3+ 按需评估,决议 Q1 预留);配方不进 GT 粉碎机/切割机([food-processor](food-processor.md) §8 边界)。

## 2. 原料侧

- **来源**:原版动物圈养;饲料 = 豆粕/玉米(作物链已有归属),饲料→繁殖激励闭环成立;
- **击杀掉落**:生肉(按肉种区分)+ 下水小概率掉落(已定案:牛肝/牛肠/百叶/牛肚/猪肝/猪大肠/羊杂/鸡胗/鸡肝/鱼杂);
- **肉源规模化(决议 Q5)**:中后期中央厨房量产的肉流瓶颈,以**通用蛋白质掺混分流**缓解(香肠/肉馅类接受掺混,淀粉肠叙事;通用蛋白质已在 M0 新增清单);屠宰场多方块延后 M3+,与 Q1 预留衔接。掺混品独立 SKU、按合理处理原则命名,不得冒充纯肉。

## 3. 分割(决议 Q1)

- **切配机电路 8"分割"**(使用 food-processor 预留槽位):输入 = 生肉(按种),输出 = 肉排 + 骨 + 油脂(概率产物);碎肉为概率副产,回流绞碎(与既有"切丁边角回流"小循环同构);
- **边界**:切片(电路 1)= 烹饪形态;分割(电路 8)= 屠宰出成(带骨/油脂副产)。两者产物不重叠;
- **生熟维度**:分割只接受生肉(处理合理性含生熟维度,决议已定;熟肉细切走烹饪侧);
- **不引入胴体物品**:零新增物品类别、不动原版掉落结构。

## 4. 腌制(决议 Q6)

- **引入亚硝酸钠**:复用 GTCEu 已有 `sodium_nitrite`(`FirstDegreeMaterials.java:1669`,现仅解毒药配方产出 `AntidoteRecipes.java:179`,用途空白、零冲突);上游自建:**硝石 `saltpeter`(`FirstDegreeMaterials.java:541`)→ 亚硝酸钠**(化学釜);
- **腌制剂配方**:亚硝酸钠 + 盐 + 香料 → 腌制盐(混配:搅拌机或化学反应釜);
- **时间型腌制工序**(火腿/培根坯):挂后处理厂腌制模块;
- 与罐头防腐剂的分工:亚硝酸钠 = 腌制入味(肉品线),苯甲酸钠/山梨酸 = 罐头防腐([packaging-and-canning](packaging-and-canning.md) 决议 3)。

## 5. 烟熏(决议 Q2)

- **工业烟熏 = 后处理厂第二/三模块**(框架现成,乳品决议 5 已预留;只做并行不做环境参数);模块顺序:熟成 → 腌制 → 烟熏;
- **手工烟熏 = 原版烟熏炉**:datapack 配方即可接入本模组生坯(如生培根),零机器资产成本;
- 后处理厂模块清单状态:熟成(乳品)+ 腌制、烟熏(本线)+ 菇房(食用菌线,待对齐)。

## 6. 香肠链

- 肠衣 = 猪大肠刮制(决议已定源);刮制工序:切配机(剥皮/绞碎类操作,具体电路待定);
- 灌制:肉馅 + 香料 + 肠衣 → 生香肠;**机器指认待定**,候选成型压机(非消耗模具,与"面团→曲奇"食品先例同机,M0 §3 已证);
- 生香肠 → 烟熏(后处理厂)/ 熟制(通用烹饪机)→ 香肠 SKU 清单待定(风干肠/烟熏肠/午餐肉等);
- 掺混品:肉馅 + 通用蛋白质 + 淀粉 → 淀粉肠(独立 SKU)。

## 7. 副产与材料

| 流向 | 路线 | 状态 |
| --- | --- | --- |
| 骨 → 明胶 | **复用 GTCEu `gelatin` 材料本体**(决议 Q3):食品级路线 = 骨 + 水 → 明胶(高压釜或化学釜,LV/MV);HV 洁净室路线(胶原蛋白+磷酸+水,`GrowthMediumRecipes.java:101-114`)保留为并行第二路线;下游琼脂不受影响 | 已定案 |
| 油脂 → 猪油/牛油 | 分割概率副产油脂(按种)→ 提取机 → 猪油/牛油(牛油 M0 已确认需新增) | 已定案 |
| 牛油 → 润滑剂 | **照鱼油先例**(`DistillationRecipes.java:98`:鱼油 1200mB → 润滑剂 500mB)加一条蒸馏路线 | 已定案(决议 Q4) |
| 牛油 → 蜡烛 | 固化机"牛油+线→蜡烛"替代配方(先例:`VanillaStandardRecipes.java:1175` Wax 固化制蜡烛);与 Wax 并行,历史叙事成立(牛油蜡烛) | 已定案(决议 Q4) |
| 牛油/猪油 → 食品 | 油炸高档介质(通用烹饪机"炸"模式,与植物油分档)、烘焙起酥 | 已定案(决议 Q4) |
| 下水 → 菜肴 | 猪大肠→肠衣;其余下水按合理处理原则进菜肴名录(牛杂汤/卤煮/爆炒类),回补 dishes-and-gains | 名录回补待做 |

## 8. 电压映射(定性,数值待定案)

分割与刮制 = 切配机(LV,既有);明胶食品级 = LV/MV;腌制混配 = MV;后处理厂腌制/烟熏模块 = 与乳品熟成同框架;牛油蒸馏 = 蒸馏塔(多方块)档位。

## 9. 遗留 / 待定(实现期处理)

1. **灌制工序机器指认**(§6):成型压机 vs 其他;
2. **分割出成率与概率**:肉排/骨/油脂/碎肉的产出数值;
3. **香肠 SKU 清单**:品类、命名、与 SoL 多样性计数的对应;
4. **下水菜肴名录回补**:dishes-and-gains §名录补充;
5. **骨的下游明细**:明胶出成、骨粉/骨肥是否接 GT 肥料;
6. **猪油/牛油材料形态与 id**:流体/固体/锭,注册粒度;
7. **掺混品命名与 SKU 细则**(§2、§6);
8. **品质档定位**:腌腊/肠类在基础/精制两档中的归属——与 packaging-and-canning §11.2-1(罐头品质定位)一并定。
