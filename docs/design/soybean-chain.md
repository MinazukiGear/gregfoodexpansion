# 大豆加工线(酱油链)(Soybean Chain)

> **本文档记录 GregFood Expansion 大豆深加工全线的当前设计。** 经讨论定案的内容标注 **[已定案]**,本文新增细节与数值标注 **[草案]/[待定]**。尚未定案的内容集中列在文末。
>
> 决议来源:2026-09-07 专项讨论——**全线**(豆油/豆浆/豆腐/酱油/豆粕同文档)、五段工艺全复用现有机器、M1 发酵槽承载、**酱油多变体(生抽/老抽等)与豆腐按凝固剂分品类、凝固剂为消耗品**、命名与数值资产按建议。

## 1. 定位与范围

**定位**:M1 的配方链旗舰——零新机器,整链挂在现有机器上(M0:GTCEu 发酵槽配方空间近乎空白,本链是其最高优先复用点);同时提供 M1 的食用油来源(豆油)。

**范围**:大豆全线——豆油、豆浆、豆腐(多品类)、酱油(多变体)、豆粕及副产循环。

**非目标**:味精/柠檬酸等发酵生化(支柱 D 专项);腐乳、豆豉、味噌(后续批次);熟成室大型化(M2 评估);本链无手工工具路径(机器链,刻意)。

## 3. 工艺路线 [已定案]

| 段 | 配方 | 机器 | 产出 |
| --- | --- | --- | --- |
| 筛分 | 小麦 | 筛选机 | 精制面粉 + **麸皮**(副产) |
| 磨浆 | 大豆 + 水 | 搅拌机 | 豆浆 + **豆渣**(副产) |
| 蒸煮 | 大豆 + 水 | 通用烹饪机(蒸,电路 2) | 煮大豆 |
| 拌曲 | 煮大豆 + 麸皮 + 种曲 | 搅拌机 | **曲料**(2026-09-08 实现期新增,见 §12) |
| 制曲(快) | 曲料 | 发酵槽 | 曲 ×2(种曲已拌入,接种发酵) |
| 制曲(自然) | 煮大豆 + 麸皮 | 发酵槽 | 曲(超长时长、低产率,**首次启动用**) |
| 接种 | 曲 | 发酵槽 | 种曲 ×4(自举闭环,消耗制) |
| 发酵 | 曲 + 盐水(GTCEu `SaltWater`) | 发酵槽 | 发酵醪(**长档时长,慢工艺招牌**) |
| 压榨 | 发酵醪 | 蒸馏室(2026-09-08 由提取机改挂,提取机无流体输入槽,见 §12) | **生抽** + 酱渣(副产) |
| 调制 | 生抽 + 焦糖糖色 | 搅拌机 | **老抽** |
| 榨油 | 大豆 | 提取机 | 豆油 + **豆粕**(副产) |
| 点卤 | 豆浆 + 凝固剂 | 通用烹饪机(煮,电路 1) | 豆腐/豆腐脑(见 §5) |
| 千叶混配 | 豆浆 + 精制面粉 | 搅拌机 | **千叶豆腐坯**(2026-09-08 追加,见 §5) |
| 千叶定型 | 千叶豆腐坯 | 真空冷冻机 | 千叶豆腐 ×2(真实工艺为冷冻定型) |
| 焦糖 | 糖 | 通用烹饪机(煮,电路 1) | 焦糖糖色 |

**曲种双轨自举 [已定案]**:自然发酵(慢、低产)完成首次启动 → 接种闭环(曲→种曲)进入快速量产;村民交易种曲为可选补充。

## 4. 酱油变体 [已定案]

- **生抽**(基础酱油):压榨直接产物,`#forge:soy_sauces` 通用引用;
- **老抽**:生抽 + 焦糖糖色调制,红烧类菜肴**硬性引用老抽本体**(上色语义,变体间不可互换);
- 变体体系可扩充(酱油膏、蒸鱼豉油等候选),新增变体 = 新调制配方,不推翻结构;
- 酱油为半成品/调味料,**不带品质档**(中间品口径一致);瓶装经由装罐机通用灌装逻辑(M0:CannerLogic)完成。

## 5. 豆腐体系 [已定案:凝固剂消耗、多品类]

**凝固剂为消耗品**(非催化剂)。点卤在通用烹饪机煮模式完成,凝固剂种类决定豆腐品类:

| 凝固剂(消耗) | 产出 | 口味定位 |
| --- | --- | --- |
| 苦卤(`bittern`,mB) | **北豆腐** `firm_tofu` | 质紧,炒/炖类(麻婆豆腐候选) |
| 石膏(硫酸钙,粉尘) | **南豆腐** `soft_tofu` | 质嫩,汤/蒸类 |
| 凝固剂(少量) | 豆腐脑 `tofu_pudding` | 基础档早餐,可直接食用 |
| 葡萄糖酸内酯路线(葡萄糖化学) | 绢豆腐 | **后期候选**(HV+ 化学,不进 M1) |
| (无凝固剂)粉体混配+冷冻 | 千叶豆腐 `qianye_tofu` | 弹性质感,切片煎炒类;真实工艺为大豆蛋白+淀粉,**已切淀粉**(2026-09-08 淀粉糖浆链落地,[starch-chain](starch-chain.md) §4;此前曾用精制面粉代用) |

- M0 补充查证:石膏与氯化镁**均确认存在**——两品类并行落地(苦卤由氯化镁 + 水 经搅拌机制取,石膏直接消耗粉尘);
- 豆腐为中间品食材,直接食用时按**基础档**数值(食材口径,无品质标记)。

## 6. 副产与循环 [草案]

- **豆粕**(榨油副产)与**酱渣/豆渣**:统一向饲料/农业方向消化(动物繁殖饲料候选配方),不堆积;
- **豆油**入 `#forge:cooking_oil`,M1 即可喂给通用烹饪机的炒/炸模式——大豆线是 M1 油源答案;
- 高汤体系(支柱 B 煮模式副产)与酱渣方向互不冲突。

## 7. 数值框架 [全部待定,实机定案]

- 时长分层:发酵段为全模组**长档**(慢工艺定位);制曲中档;磨浆/调制等常规短档;
- 发酵槽配方 EU 取低位(8–16);其余机器按各自标准;
- 消耗型凝固剂用量:苦卤按 mB、石膏按粉尘份数,数值待定;
- 产率:曲/种曲回投倍率、生抽产率、副产概率,全部待定。

## 12. 实现期调整记录(2026-09-08,源码查证驱动,待用户追认)

以下三处偏离 §3 已定案机器表,均为 GTCEu 7.5.3 配方类型 IO 上限的硬约束,非设计偏好:

1. **拌曲步 + 曲料(`koji_batch`)新增**:发酵槽 `FERMENTING_RECIPES` 配方 IO 为 **1/1/1/1**(`GTRecipeTypes.java:272`),"煮大豆+麸皮+种曲"三原料无法同批进槽 → 新增搅拌机"拌曲"步(煮大豆+麸皮+种曲→曲料 ×2),发酵槽跑"曲料→曲 ×2"。种曲由"回投不消耗"改为"消耗、由接种 ×4 倍增覆盖"(1 曲→4 种曲→4 批曲料→8 曲,正反馈闭环,经济性不劣于回投);
2. **压榨改挂蒸馏室**:提取机配方 IO 为 1/1/0/1(`GTRecipeTypes.java:258`),**无流体输入槽**,发酵醪(流体)进不去 → 压榨挂蒸馏室(1/1/1/1,流体进出+物品副产),与回油产线同机器;
3. **盐水以流体进料 + 复用 GTCEu SaltWater**(§10-5 收口,两轮):同 1,发酵段物品槽只能装曲,盐水必须以流体进料;自建 `brine` 与 GTCEu `SaltWater` 语义重复,已删除自建材料,发酵配方改引 `GTMaterials.SaltWater`(自制盐水配方一并删除,GT 既有配方口径:2 盐尘+1000mB 水→1000mB)。

数值首版基准(§7 待定,实机平衡微调):筛分 100t/16EU、磨浆 200t/8EU、蒸煮 200t/12EU(烹饪机 c2)、拌曲 200t/8EU、制曲自然 1200t/8EU、制曲快 400t/8EU、接种 300t/8EU、发酵 1200t/16EU、压榨 200t/16EU(醪 1000→生抽 800+酱渣)、老抽调制 100t/8EU(900+100→1000)、榨油 200t/16EU(大豆 ×2→豆油 60+豆粕)、焦糖 200t/12EU(c1)、点卤 200t/12EU(豆浆 250 + 苦卤 50/石膏 1/苦卤 10)。麸皮筛分副产率 30%(+500 提升档)。
