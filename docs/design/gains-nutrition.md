## 1. 三因子增益

**增益 = 工艺 × 配料 × 品位**,管线自动计算,不做逐菜手调:

- **工艺**:煮(再生)蒸(吸收)炒(急迫)炸(速度)烤(饱和)腌/冻干/干吃(折扣)…
- **配料**:有效成分维度贡献效果种类(辣素→速度类、咖啡因→急迫类、茶多酚→再生类…);
- **品位**:时长/强度乘区,天然育种可超合成基准(意义存续双轴)。

## 2. 增益梯度(随档上移,天花板唯一)

| 档 | 梯度 |
| --- | --- |
| 手工 | 无增益或极弱(手做链定位=过渡与多样性) |
| LV | 基础档 |
| MV | 精制档(巴氏/奶酪等配料门槛) |
| HV | 强化档(味精时长加成:可选投入,只加时长不加强度) |
| IV | 功能食品 I/蛋白归一档(多路线蛋白并轨) |
| LuV | 培养蛋白/合成配料档(生物反应器) |
| ZPM | 全效保留版(HPP 免加热灭菌,增益零损耗) |
| UEV/UIV | 质构(强度突破)/缓释(时长突破) |
| **MAX** | **造粮机:全模组增益天花板唯一归属** |

原则 8:任何中间档产物增益不得与顶档天花板重叠;顶级数值只留给终局。

## 3. 独家锁定(合成配料进不了的配方)

- **鲜食类**(沙拉/刺身):定义上拒绝合成配料;
- **活菌发酵类**(酸奶/泡菜/酒):必须活菌种;
- **风味独占类**:高品位天然香料触发独家增益,合成风味(UHV)只给标准味。
