## 1. 定位与分工矩阵

## 2. 冻干线(决议 Q1、Q2)

### 2.1 果蔬脆片零食线

预处理(切配机切片/切块)→ 真空冷冻机 → 冻干脆片 → **直接吃**(精制档增益)。SKU 随作物批次滚动注册(冻干草莓/冻干苹果片/冻干蘑菇…),合理处理原则。

### 2.2 方便主食线(二段式,决议 Q2)

冻干面/速食汤块,两种吃法:

- **干吃**:增益时长 ×0.5(2026-09-07 横向专题 10 已定,dishes-and-gains §2.1 修正管线);
- **复水**:冻干品 + 热水/高汤 → 复原菜肴,增益完整。复原菜 SKU 口径(复用原菜肴 id 或独立 SKU)按 SoL 计数在实现期定(§6-1)。

高汤复水与 packaging 11.2-5(介质流体清单)天然汇流——高汤细则定案后一并收口。

## 3. 防腐剂(决议 Q3:**全链自建**)

用户决议按 B 档:两种防腐剂均走完整上游,**全部真实化学、无一步假合成**。

### 3.1 苯甲酸钠链(上游已证)

甲苯(GTCEu 已有,石化产出 `PetrochemRecipes.java:241/257/293`)→ 氧化 → **苯甲酸**(新)→ +氢氧化钠(已有,`FirstDegreeMaterials.java:1022`)中和 → **苯甲酸钠**(新)。

### 3.2 山梨酸链(全自建)

| 步骤 | 配方 | 上游 |
| --- | --- | --- |
| 乙醛 | 乙醇氧化脱氢 | 乙醇已有 |
| 乙烯酮 | 乙酸高温裂解 | 乙酸已有(M0 可复用清单) |
| 巴豆醛 | 乙醛×2 醇醛缩合 | 上步 |
| 山梨酸 | 巴豆醛 + 乙烯酮 | 上两步 |

### 3.3 资产与风险

- 合计 **6 个新材料**(苯甲酸/苯甲酸钠/乙醛/乙烯酮/巴豆醛/山梨酸)+ 约 8 条配方;
- 风险(用户知悉并接受):乙醛/乙烯酮/巴豆醛暂无第二消费点——缓解:按 GT 化学品风格注册,均为标准化工中间体,未来配方扩展天然接入;
- **落点(收口 packaging 11.2-3)**:肉类/水产罐头**必需**投入;果蔬罐头/冻干**不需要**(高糖高酸环境自身抑菌,合理处理原则成立)。

## 4. 品质档与营养密度(决议 Q4,收口 packaging 11.2-1/2)

- 罐头/冻干**纳入精制档、无时长折扣**;单件营养 = 精制菜肴一半量级(具体数值实机调整);
- 理由:时空转移动因已去除,堆叠便携本身就是奖励,再加折扣是双重惩罚;低营养密度控制"一格背包顶一天"。

## 5. 罐头箱(决议 Q5,收口 packaging 11.2-4)

- 容量 **16**(4×4),与堆叠 64 整倍数(4 箱 = 1 组);
- 装箱/拆箱 = 打包机(Packer)静态配方,复用现成机制。
