## 治理规则

1. 每个新作物登记四要素:**类别 / 环境参数 / 工业归属 / 贴图预算**;
2. 无明确工业归属(至少一条加工链)的作物不立项;
3. 长尾池作物凭加工链杠杆(如蚕豆→豆瓣酱)可跳过排队直接立项。
